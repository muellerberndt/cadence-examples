How to read this brain

The retina, body, retained sensory traces and route recall constrain one recurrent circuit. Local repairs spread through connected visual, association and motor populations. Motor output commits after settling; positive and negative nudges estimate learning eligibility. These nudges are not imagined future games.

Every core neuron and synapse is drawn, as one integrated brain: regions are placed next to the regions they connect to, the retina and afterglow keep the eye’s layout (fovea beside periphery, three channels), and each neuron sits among the neurons it talks to. The tissue’s brightness is the chosen signal, the hot glow is what changed in the last iterations, synapses light up when their source changed, and particles travel along synapses in proportion to the message sent. Addressed route memories (one point per stored address, each wired to the recall neurons it writes) and the value readout are drawn in the same brain, as attachments: they do not run extra equilibrium iterations. All stored addresses, including inactive game and mirrored banks, are included. Clamped afterglow and context carry real retained traces; recurring activity need not form oscillations.

“Every repair” holds the game frame while replaying every stored solver iteration. “Gameplay” selects the motor state per decision for normal-speed viewing; all intermediate repairs remain available through Step. Browser or disk limits can slow playback; frames and neural states always move together. Values are stored losslessly. At this scale many connections overlap: zoom and inspect to separate them.

This run uses a pilot trained by imitation, followed by trial and error on a GPU. It records a preselected demonstration start with learning enabled. The score is not a held-out benchmark, and no stage is cleared. The brain replay retains 10,870 settling iterations across 527 game decisions, including 59 nonzero signed dopamine signals. No ROM or emulator is required.

Cadence uses neurons with local state, declared synapses, readback and retained records. Local feedback repairs the jointly constrained state across its visual, association and motor regions. Route stores and the value readout are explicit attachments, distinguished on the map.
