Cadence Recall

A memory with no trained parameters. Writing a pair is one Hebbian outer product between a key owner and a value owner; asking is a settlement with the key clamped. Write a context, then click any key.

What this is

128 key owners and 128 value owners, every key joined to every value by a seam that starts at zero: 32,768 seams and nothing else. Writing k → v adds one unit to the seam between k's owner and v's owner, both ways, because the two were active together. Nothing else in the net changes.

Asking clamps k's owner at 3.0 and settles: the value owners come to rest and the most active one is the answer. The first step after the clamp is exactly an attention read over the stored pairs (a modern Hopfield network); the settlement cleans it. The page reports both.

There is no window and no context length: the context is whatever was written. What a memory like this cannot do is keep keys apart when they resemble each other; here every key is one owner, so there is no interference at any length.
