Cadence Recall

A memory that learns on every write. It reads the old association, compares it with the new value, and writes the difference. Write a context, then change a key and ask again.

What this is

128 key owners read 128 value owners through 16,384 mutable fast seams. Each write corrects the difference between the requested value and the current readback, using Cadence's residual memory rule.

Repeatedly writing an old value does not prevent a later correction. Capacity here is 128 distinct one-hot keys; a dictionary also solves this explicitly addressed task.
