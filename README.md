# Cadence examples

**No examples are currently accepted.** Every application is being rebuilt from
scratch around an ongoing experience loop: observe, remember, predict, act, and
learn from the outcome.

An application enters this repository only after its fresh implementation passes
its behavioral, learning, intervention, and reproducibility gates. A working UI or
a plausible demonstration is insufficient.

The implementation specifications are in the workspace's
`cadence-paper/EXPERIENCE_BASED_LEARNING_PLAN.md`. Candidate implementations belong
in their research repositories until they pass. Old code, weights, memories, and
results are not dependencies of the new program.

For the library's single ongoing loop, read the
[Cadence quickstart](https://github.com/muellerberndt/cadence/blob/main/docs/quickstart.md).

Check this empty gallery with `python tools/check_gallery.py`.
