Each connected region settles into the same joint state under the current input. The body acts, the boundary changes, and settling begins again. A small equation error means self-consistency; it does not guarantee the best possible action.

How to read this view

Each region groups actual neurons by function; lines are their real synapses. Supplied sensing, steering and body adapters are labeled above the graph. Every neuron and synapse is mapped; dense synapses overlap when zoomed out. Wheel or pinch to zoom, drag to pan, and use Fit whole brain to return. Region tints identify function: visual purple, motor cyan, memory violet, sensory green, planning rose. Hover or tap a neuron for its value. Colors use dimensionless model units. The heatmap shows positive values in amber and negative values in blue; its smooth halos are a display overlay around actual neurons. Turning it off restores the node view. Plasticity highlights recent learned weight changes separately. The trace plots peak activity. Couplings that change with arm geometry are not counted as plasticity.

Follow settling automatically reconstructs sampled settling runs from their captured inputs, initial states and couplings. It slows the early settling steps and compresses the later ones; the live body continues. Components may use different iteration counts. Rapid updates are coalesced, so this is not a recording of every body tick. Violet rings fade for one second after a displayed activity change: this is display history, not short-term memory in the controller. Replay lets you inspect one captured settling run at a fixed rate. Release input sets the drive to zero in an isolated copy, exposing recurrent decay or ringing; it does not control the body or imply a learned short-term memory. No oscillation is added for appearance. Memory-only circuits have no recurrent replay. Live body operation continues while you inspect a copy.

Behavior colors: green = food or goal reached; blue = seeking or moving; amber = correction, changed expectation or blocked route; gray = paused or idle. “Happy” would be an informal name for a positive outcome, not a measured feeling. These status colors are separate from signed circuit values. Text labels always identify the observed event.

These models do not simulate neurotransmitter concentrations. Activity, input drive and weight changes are different signals. Clinical fMRI measures a blood-oxygen-related signal; PET uses specific tracers to study molecular targets. Neither is a generic live map of all neurotransmitters.
