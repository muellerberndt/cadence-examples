How to read this view

The medical-style silhouette is a layout metaphor, not an anatomical scan. Dots and seams are actual model elements; hover for owner values in dimensionless model units. The heatmap shows positive values in amber and negative values in blue; its smooth halos are a display overlay around actual owners. Turning it off restores the node view. Plasticity highlights recent learned weight changes separately. The trace plots peak activity. Couplings that change with arm geometry are not counted as plasticity.

Replay recomputes the captured numerical settlement and slows it down. Release input sets the drive to zero in an isolated copy, exposing recurrent decay or ringing; it does not control the body or imply a learned short-term memory. No oscillation is added for appearance. Memory-only circuits have no recurrent replay. Live body operation continues while you inspect a copy.

These models do not simulate neurotransmitter concentrations. Activity, input drive and weight changes are different signals. Clinical fMRI measures a blood-oxygen-related signal; PET uses specific tracers to study molecular targets. Neither is a generic live map of all neurotransmitters.
